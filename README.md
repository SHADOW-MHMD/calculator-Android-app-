# Scientific Calculator Android App

Android scientific calculator with a modern UI and support for common scientific operations:

- Basic arithmetic: `+`, `-`, `×`, `÷`, `%`
- Parentheses and powers: `( )`, `xʸ`, `x²`
- Constants: `π`, `e`
- Scientific functions: `sin`, `cos`, `tan`, `asin`, `acos`, `atan`, `ln`, `log`, `sqrt`, factorial

## Build an installable APK

```bash
./gradlew assembleDebug
```

APK output:

`app/build/outputs/apk/debug/app-debug.apk`

## Build an Android App Bundle (AAB)

```bash
./gradlew bundleRelease
```

AAB output:

`app/build/outputs/bundle/release/app-release.aab`
